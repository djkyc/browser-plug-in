怎么加账号

不用输密码：
Gmail不用建项目、不用填密钥：Client ID 是内置的，给每个号点“登录”，在 Google 登录页选号就行。token 约 1 小时，到期自动静默续。自动发现扫 u/0～u/4（2-3 个号就是 u/0、u/1、u/2），找到后也要各登一次。
Outlook默认用自己的 Azure 应用（下面那个就是，改不了也不用改），每个号点“登录”即可，互不干扰。能回邮件、标已读、归档、删除、写邮件；Azure 应用要加 Mail.ReadWrite、Mail.Send 权限，旧 token 只有读权限，四个号都要重登一次。
Proton先在标签页登好 mail.proton.me，等加载完，扩展抄下会话头再查未读；过期重开一次。用的还是 Email Notifier 同款内部接口，不是官方登录。

数据

所有账号和设置只存在这台浏览器的 chrome.storage.local 里，不发到任何服务器。卸载扩展即删除。

WebDAV 备份

把账号和设置备份到你的 WebDAV 网盘，换电脑时再从这里恢复。只备份账号和设置，不备份登录 token 和 WebDAV 密码，恢复后去账号表里重新点“登录”即可。坚果云的密码要用“应用密码”（坚果云网页版 → 账户信息 → 安全选项 → 添加应用密码），不是登录密码。
